# messenger skills

- `first-run-setup`: 初回起動、ローカルランナー確認、connector 設定案内。
- `check-inbox`: ローカルSQLite / runner payload の未処理 message を triage する。
- `draft-reply`: 返信案と asks document を作る。
- `handle-ask-answer`: asks 回答後にローカルランナーへ送信または close を任せる。
- `recover-backlog`: 久々起動時の backlog、stuck state、backfill を整理する。
